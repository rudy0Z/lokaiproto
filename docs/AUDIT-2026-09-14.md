## 3. Findings and dispositions

### 3.1 P0 — desktop chat cold-start rendered empty
`seedTurnForConversation` (Chat.tsx:72) was defined and never called; rendering is
hybrid-turns-only, so seeded conversations drew an empty column.
**Fixed:** the conversation-switch effect now seeds the prepared turn for the two
seeded conversations (`consumer`, `out-of-scope`).

### 3.2 P0 — boundary conversation answered as the consumer scenario
`runPreparedInput` routes by the global `scenarioId`; the URL never synced it, so
`/desktop/chat/out-of-scope` answered as the consumer matter.
**Fixed:** the same effect maps `chatId` → `selectScenario` (`out-of-scope` →
`out_of_scope`).

### 3.3 P1 — desktop clarify had no tappable answers
The clarify copy said "pick the closest answer below"; desktop rendered only the
three text zones.
**Fixed:** clarify turns now render the mobile chat's option rows (in the Turn and in
the empty state), routing through the same `resolveClarify` path.

### 3.4 P1 — LogoMark invisible in dark mode
The tile re-pointed to the cream anchor while the glyph stayed hardcoded cream
(`#F7F4ED`) — a blank tile in dark.
**Fixed:** the glyph now rides `var(--role-on-anchor)`, the ink paired with the anchor
in both themes by the contrast gate.

### 3.5 P0 (review) — home quick-start chips were imperceptible
Chips used a white fill on a cream ground (≈1.06:1) with no border — they read as
plain text.
**Fixed:** the chips move to the anchor-tint fill with anchor ink — the paired,
contrast-gated treatment (both themes).

### 3.6 Composer contradicted two of the repo's own laws
`backdrop-filter` glassmorphism plus **border AND shadow** on one surface.
**Fixed:** a solid raised surface with shadow-only separation; the focus ring is the
role tint, and the dark variant follows the same role.

### 3.7 Split token truth
`tokens.dtcg.json`, the `index.css` scale blocks, and `shared.tsx`/`theme.ts`
disagreed numerically, and the CSS `--type-*`/`--space-*` blocks had **zero
consumers** while disagreeing with the live TS scales (display 44/32px vs 56/36px).
**Fixed:** the dead CSS blocks are deleted and replaced by pointer comments to the
live sources; the `C.*` motion literals are synced to the CSS palette (saffron
`#E9852B`→`#E27A24`, etc.); `--elevation-*` is re-pointed to the warm `SHADOW`
recipes (one elevation system); `tokens.dtcg.json` is **regenerated from live
values** and labelled generated.

### 3.8 Documentation contradicted code
- `README.md` was Figma-Make boilerplate. **Fixed:** real project README.
- `DESIGN.md` / `PRODUCT.md` specified Inter + a bottom nav (both superseded:
  Hanken Grotesk and the drawer). **Fixed.**
- `AGENTS.md` said Lucide/Phosphor are "retired repo-wide, enforced by verify:demo"
  — Phosphor is a legitimate tier-3 for inline content icons, and no gate checked
  icons at all. **Fixed:** the icon law now states the three tiers accurately.
- `routes.tsx` carried a "bottom nav" comment. **Fixed.**
- Historical docs (`HANDOFF.md`, `design-changelog.md`, the June elevation plan, the
  `.design-os/` set, `guidelines/`) described superseded eras as if current.
  **Fixed:** marked HISTORICAL / archived.

### 3.9 Scaffold and dead weight
`@figma/my-make-file` package name; ~45 zero-reference dependencies (all Radix,
Emotion, recharts, lucide-react, @fontsource/inter, …); a dead `components/figma/`
file; 6 tracked vite logs; prompt-residue in `src/imports/`; an empty guidelines
template; ATTRIBUTIONS claiming shadcn/Unsplash.
**Fixed:** see §5 (hygiene).

## 6. Open items (owner decisions, not defects)

- **Radius scale wording** — the "exactly 3 radii" claim in the review plan did not
  match the system, which legitimately uses `xs/control/card/pill/full`. The docs now
  state the real scale; retiring `xs` remains an open visual decision.
- **Answer vs pronounce type size** — `TYPE.editorial` and `TYPE.editorialSm` are both
  24px today, so the refusal no longer out-sizes the answer. Restoring the 22/28 split
  is a design decision for the upgrade pass.
- **Four `fontWeight: 700` sites** remain (notice letterhead, capture overlay, demo
  disclosure) — deliberate meta contexts, not body text; the type system's cap is 600.
- **Tailwind pipeline** — `index.css` still imports `tailwind.css` (preflight/reset
  only; no utility classes in use). Removing it is safe but is a visual-QA pass of its
  own; left in place and documented.
- **1.4 MB main chunk** — vendor code-splitting is a build-config change deferred to
  the performance pass.
